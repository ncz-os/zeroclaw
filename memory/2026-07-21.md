## Lesson learned
When manually resolving a conflict where both sides have a `use
foo::bar;` line, also check whether the *use* (the call site) uses
the bare name or the fully-qualified path. If the call site is
fully-qualified, the imported name is dead and the import line is
just cruft from the resolution.
